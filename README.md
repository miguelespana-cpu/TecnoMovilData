# TecnoMovil Data

## Descripcion

Proyecto academico desarrollado en Java 17 que aplica
programacion funcional para procesar datos simulados
de un sistema de transporte urbano.

## Objetivo

Analizar registros de pasajeros mediante Streams,
expresiones Lambda y operaciones funcionales.

## Funcionalidades

1. Calculo de afluencia por estacion.
2. Identificacion de horas pico.
3. Identificacion de rutas mas utilizadas.
4. Patrones de viaje por usuario.
5. Calculo del tiempo promedio entre estaciones.
6. Deteccion de sobrecarga en rutas.

## Tecnologias

- Java 17
- Visual Studio Code
- Java Streams
- Expresiones Lambda
- Collections API

## Ejecucion

Compilar:

javac -d out src/model/Registro.java src/data/GeneradorDatos.java src/service/AnalizadorDatos.java Main.java

Ejecutar:

java -cp out Main
